# 🚀 AWZION Multicálculo

Sistema de Multicálculo de Seguros desenvolvido em PHP, CSS e MySQL.

## 📌 Sobre o projeto

O AWZION Multicálculo é um sistema criado para auxiliar corretores e empresas de seguros no gerenciamento de:

- Clientes
- Veículos
- Cotações
- Relatórios
- Login administrativo
- Painel de controle

## 🛠️ Tecnologias utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Git & GitHub

## 📂 Estrutura do projeto

```bash
auth.php
cotacao.php
painel.php
index.php
login.php
logout.php
relatorio.php
style.css
veiculo.php
```

## 🎯 Objetivo

Criar uma plataforma moderna e funcional para automatizar processos de cotação de seguros.
